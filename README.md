## Usage

Load a midi file and connect a midi keyboard. 

Play along and get a score or enable "wait for me" mode to learn new tracks.

For smaller midi keyboards, a "dynamic octave shift" setting is available.
It does not count notes outside your keyboard's range and warns you if you need to change the octave.

## Finding songs

I found <https://onlinesequencer.net> to be quite a good source for new tracks.

The search function ranks the tracks weirdly so i used my search engine to find songs on the site:
